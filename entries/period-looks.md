# Period Looks

Named nostalgia registers — internet-era aesthetics reconstructible as
recipes from this dictionary's ingredients. Naming the period loads the whole
costume; this entry is the wardrobe index.

## You know it when you see

- **Y2K** — chrome blobs ([[specular-metallic]] + [[liquid-ripple]] shapes), lens flares, iridescent gradients, inflatable type, tech-optimist silver/blue
- **Frutiger Aero** (mid-2000s) — glossy bubbles, [[caustics]]/water, grass-and-sky imagery, glass buttons ([[skeuomorphism]] glossy wing), humanist sans, benevolent-tech green/blue
- **Vaporwave** — magenta/cyan dusk [[gradients]], marble busts, [[crt-scanlines]] + VHS wear, grids to the horizon, Japanese type as ornament
- **Web 1.0 / GeoCities** — tiled backgrounds, beveled buttons, hit counters, GIF energy ([[brutalism]]'s chaotic ancestor)
- **Memphis / 80s–90s print** — squiggles, confetti shapes, clashing brights on grids ([[print-artifacts]] adjacent)

## Dials

- **commitment depth** — accent notes (one chrome blob in a modern layout) vs full costume (every element period-correct); half-committed with modern polish usually beats theme-park total
- **period accuracy vs remix** — faithful reconstruction (era-correct artifacts, fonts, even imperfections) vs the modern remix (period vocabulary, current craft: real type scale, [[color-roles]] discipline underneath)
- **artifact layer** — each era's wear: Y2K = flares + chrome; aero = gloss highlights; vapor = VHS [[glitch]] + scanlines; web 1.0 = GIF dither; the wear layer authenticates
- **type wardrobe** — the era's faces ([[typographic-voice]]): techno/rounded (Y2K), humanist sans (aero), serif+CJK mix (vapor), Times/Comic (web 1.0)
- **irony temperature** — sincere revival vs wink; affects how many flaws to reproduce deliberately

## Techniques

Each period is a composition of existing entries — the technique is the
recipe list:

- **Y2K** — [[specular-metallic]] chrome text (layered gradients or 3D),
  [[iridescence]], [[lens-flare]], blob [[shape-language]] via
  [[sdf-rendering]]/SVG, inflated type (heavy rounded faces + gloss).
- **Frutiger Aero** — [[skeuomorphism]] gloss buttons (hard white top
  highlight), [[frosted-glass]], bubble [[particles]], nature photography
  [[image-treatment]] (saturated green/blue), soft [[glow-bloom]].
- **Vaporwave** — sunset [[gradients]] + perspective grid (one-point lines
  to horizon), [[crt-scanlines]] + [[glitch]] + [[chromatic-aberration]],
  statue/palm assets, [[false-color]] magenta grading.
- **Web 1.0** — tiled [[material-texture]] backgrounds, inset/outset
  borders (the beveled [[border-stroke]]), system [[typographic-voice]],
  animated GIFs; authenticity = refusing modern spacing polish.
